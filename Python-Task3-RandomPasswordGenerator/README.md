# Task 3 — Random Password Generator

## Overview

A beginner-friendly command-line password generator that creates random passwords based on user-selected character types.

## Internship Requirements Covered

- Minimum password length of 8 characters
- Uppercase, lowercase, numbers, and symbols selection
- At least two character types required
- Password generation matching selected criteria
- Input validation
- Generate another password without restarting

## Technologies

- Python
- `random`
- `string`

## Run

```bash
python main.py
```

## Security Note

This Beginner-tier implementation uses `random` as specified by the internship task. For real security-sensitive password generation, Python's `secrets` module is more appropriate.
